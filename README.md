## 🧠 21 Days SQL Challenge with IDC  

Welcome to my repository for the **IDC 21 Days SQL Challenge!**  
This space documents my **daily SQL journey** — covering solutions, insights, and practical notes as I strengthen my SQL and data analysis skills through consistent learning.  

---

### 📅 Challenge Summary  

The **IDC SQL Challenge** is a 21-day learning program designed to sharpen both **SQL fundamentals** and **real-world data problem-solving**.  
Each day introduces a fresh topic or challenge, exploring areas such as:  

- `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`  
- Joins and Subqueries  
- Aggregate & String Functions  
- Window Functions  
- Data Cleaning & Transformation  
- Query Optimization Techniques  

✨ *One query a day — one step closer to mastery!* ✨  

---

### 📁 Repository Layout  

Each folder contains the following files for that day’s challenge:  

- **solution.sql** → My SQL query for the daily task  
- **notes.md** → Concepts, takeaways, and explanations  
- **dataset.csv** → Practice dataset (if provided)  

---

### ⚙️ Tools & Environment  

- **SQL Platform:** MySQL  
- **Editor Used:** MySQL Workbench
